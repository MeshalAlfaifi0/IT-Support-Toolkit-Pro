# التطوير والاختبار

استخدم Windows وPython 3.12 x64 وبيئة `.venv` مستقلة. أوامر الإعداد موجودة في README. بعد تحديث تبعية، اختبرها قبل تغيير `requirements-lock.txt`؛ Lock يثبت التبعيات المباشرة وليس جميع التبعيات المتعدية.

## قواعد الكود

- أسماء الملفات والدوال بالإنجليزية بنمط snake_case؛ التعليقات والتوثيق بالعربية عندما تساعد على فهم السبب والعقد.
- الواجهة في `ui`، منطق النظام في `core`، التخزين في `database`، والمساعدات المشتركة في `utils`.
- لا تضف عمليات نظام حساسة داخل منشئ صفحة أو اختبار؛ تأكيد المستخدم وفحص الصلاحيات يسبقان التنفيذ.
- الاستيراد أعلى الملف. يبقى الاستيراد الكسول داخل الدوال للمكتبات الاختيارية أو لتجنب اعتماد دائري مبرر.
- استخدم وسائط أوامر منفصلة و`shell=False` عند تمرير بيانات متغيرة.
- لا تُسجّل كلمة مرور أو قيم اعتماد؛ استخدم رسائل حالة آمنة.

## أوامر العمل

```powershell
python -m ruff check app.py src tests scripts
python -m ruff format --check app.py src tests scripts
python scripts/run_tests.py --language ar
python scripts/run_tests.py --language en --scale 1.5
python scripts/check_project.py
```

`run_tests.py` ينشئ مجلدًا مؤقتًا ويضبط البيانات وQt offscreen قبل استيراد التطبيق، ويتوقف عند فشل أي اختبار. نتائج الصحة والتصدير في الاختبارات وهمية. لا تحتاج لتغيير IP أو الانضمام إلى دومين أو إلغاء طباعة فعلية لتطوير المشروع.

| مجموعة الاختبارات | الغرض |
|---|---|
| `test_repairs.py` | الاعتمادات والمهلات والحفظ والشبكة والتنظيف والأمان |
| `test_reports.py` | JSON/CSV/PDF ومحتوى طويل وUnicode وتغطية الفحص |
| `test_ui.py` | التنقل واللغة والثيم والإغلاق والإعدادات والهوية |
| `test_maintenance.py` | مقابض الطباعة وأعلام الحالة وأوامر الشبكة الآمنة |

GitHub Actions يشغل التحقق على Windows في اللغتين. إنشاء Workflow محلي لا يثبت نجاح تشغيله على GitHub؛ يجب متابعة نتيجته بعد أول رفع.

## اختبار بدء التطبيق وإعادة تشغيله

```powershell
python scripts/smoke_test.py --report artifacts/source-startup.json
python scripts/smoke_test.py --exe dist/IT-Operations-Console.exe --report artifacts/exe-startup.json
```

يفتح الاختبار صفحات التطبيق الثلاث عشرة باستخدام Qt offscreen ثم يغلقه بأمان. يحفظ لغة وثيم تجربة مؤقتة، ويبدأ عملية ثانية للتحقق من استعادتهما. لا يفحص الشكل المرئي على الشاشة؛ افحصه يدويًا على 1366×768 وتكبير 150% قبل إصدار نسخة. لا يُغيّر شبكة الجهاز أو عضوية الدومين أو مهام الطباعة.
